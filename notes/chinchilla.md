# Chinchilla

주어진 연산량에서는 모델 크기와 학습 토큰 수를 같은 비율로 늘려야 최적이라는 결과.

- [[scaling-laws]]가 제안한 배분을 수정한다.
- 기존 대형 모델 다수가 데이터 대비 과대했다는 해석이 나온다.
- 추론 비용까지 고려하면 최적점이 다시 달라진다는 점은 따로 정리할 것.
